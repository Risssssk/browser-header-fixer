Header Fixer

Chrome 浏览器扩展 · 访问指定网址时，固定添加任意自定义请求头

能做什么

按网址规则注入请求头 支持「包含 / 开头是 / 域名 / 完整 URL / 正则」五种匹配方式
任意自定义 Header 可覆盖设置、追加，或删除指定请求头；一条规则可挂多个 Header
一键启停 · 本地持久化 规则存在 chrome.storage，重启浏览器后自动生效
导入 / 导出 JSON 方便在多台机器之间同步规则，或版本管理
Manifest V3 declarativeNetRequest 无远程代码 弹窗 + 设置页

安装步骤

  1. 打开 Chrome 扩展管理页：
    chrome://extensions
  2. 打开右上角「开发者模式」
  3. 点「加载已解压的扩展程序」，选择本目录下的 header-fixer/ 文件夹
  4. 工具栏点开扩展图标，即可添加规则；也可点齿轮进入设置页
修改请求头会影响真实网络请求。请仅在你有权测试/调试的站点上使用，不要用于伪造身份或绕过安全控制。

匹配方式说明

包含      URL 中出现关键词
          例：api.example.com

开头是    URL 以指定前缀开头
          例：https://api.example.com/

域名      匹配该域名及所有子域
          例：example.com

完整 URL  精确匹配一个地址
          例：https://api.example.com/v1/me

正则      Chrome DNR 正则语法
          例：^https://api\.example\.com/

「生效范围」可限制只改 XHR/Fetch、WebSocket 或页面主文档等资源类型；不勾选则全部请求都改。

规则 JSON 示例

{
  "version": 1,
  "rules": [
    {
      "id": "r_demo",
      "enabled": true,
      "name": "测试环境 Token",
      "matchType": "domain",
      "pattern": "api.example.com",
      "headers": [
        { "name": "Authorization", "value": "Bearer xxx", "operation": "set" },
        { "name": "X-Env", "value": "staging", "operation": "set" }
      ],
      "resourceTypes": ["xmlhttprequest", "websocket", "main_frame"]
    }
  ]
}
